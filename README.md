# Console 3D Engine

Первая версия 3d-движка на Python, который рисует сцену прямо в консоли. Разрешение терминала в символах используется как пиксельная сетка, а изображение строится методом трассировки лучей (ray casting): для каждого «пикселя» из камеры пускается луч и ищется его пересечение с гранями объекта.

## Что уже реализовано

- **Визуализация произвольных 3D-объектов.** Объект описывается простой структурой данных:
  - список координат вершин (`vertices`);
  - список граней (`faces`), каждая грань это кортеж индексов вершин, идущих по периметру;
  - центр объекта (`center_coord`) и углы поворота по осям X, Y, Z.
- **Вращение объектов** вокруг собственного центра по трём осям.
- **Готовые модели** в файле `object_storage.py`: куб, пирамида, призма и другие. Нужную модель можно выбрать в `main.py`.
- **Собственные модели.** Новый объект добавляется в `object_storage.py` по тому же шаблону.
- **Подстройка под размер терминала.** Разрешение берётся из текущего размера окна.

## Как работает

1. Для каждого пикселя экрана строится луч из камеры через соответствующую точку экрана.
2. Для каждой грани по трём её вершинам строится плоскость (нормаль и свободный член).
3. Находится точка пересечения луча с плоскостью.
4. Проверяется, лежит ли эта точка внутри грани.
5. Если несколько граней перекрываются, выбирается та, что ближе к камере (по параметру луча `t`).

Вершины хранятся в локальных координатах объекта. Мировая позиция вершины считается как `rotate(local) + center_coord`.

## Структура проекта

```
main.py              # точка входа, выбор объекта и главный цикл
core.py              # функция render
object_storage.py    # описание готовых 3D-моделей
models/camera.py     # класс камеры
```

## Запуск

```bash
python main.py
```

Запускать лучше в обычном терминале, а не в среде, которая не умеет возвращать размер окна (`os.get_terminal_size()`). Размер окна лучше не менять во время работы.

## Выбор модели

В `main.py` одной строкой выбирается отображаемый объект:

```python
curr_object = cube
```

Доступные модели: `cube`, `polygonObject`, `pyramid`, `prism`.

## Создание своей модели

В `object_storage.py` добавь новый объект:

```python
my_object = Object3D(
    vertices=[(-3,-3,-3), (3,-3,-3), (3,3,-3), (-3,3,-3),
              (-3,-3,3),  (3,-3,3),  (3,3,3),  (-3,3,3)],
    faces=[(0,1,2,3), (4,5,6,7), (0,1,5,4), (1,2,6,5), (2,3,7,6), (3,0,4,7)],
    center_coord=(0, 7.5, 0),
)
```

Требования к модели:

- вершины заданы относительно центра объекта (центр в `(0,0,0)`);
- каждая грань плоская и выпуклая;
- вершины грани перечислены по периметру, а не вразнобой;
- объект должен находиться перед камерой (в нашей системе координат глубина это ось Y).
